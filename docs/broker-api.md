# 증권사 API 로 내 보유현황 자동으로 받아올 수 있나 (검토)

> 이 문서는 지식 기준 정리이고, 각 사 정책은 자주 바뀝니다. 신청 전에 공식 문서를
> 반드시 확인하세요. 특히 "개인 발급 가능 여부"와 "잔고조회 TR 제공 여부"가 핵심입니다.

## 결론 먼저

- **한국투자증권 KIS Developers 가 유일하게 편하게 붙는 선택지입니다.** 순수 REST + 개인 무료
  발급이고, 국내주식·해외주식 **잔고조회**가 다 있어서 보유현황을 그대로 끌어올 수 있습니다.
- 키움·대신·LS 는 전통적으로 **Windows 전용 COM/OCX** 방식이라 PC(윈도우)에서만 돕니다.
  (최근 REST 방식을 추가한 곳이 있으니 확인 필요)
- 삼성·미래에셋·토스·카카오페이 등 대부분은 **개인 대상 공개 API 가 없습니다.**
- **폰(PWA)에서 증권사 API 를 직접 부르는 건 불가능합니다.** 아래 "왜 서버가 필요한가" 참고.

## 증권사별

| 증권사 | 방식 | 개인 발급 | 보유잔고 조회 | 실무 난이도 |
|---|---|---|---|---|
| **한국투자증권** (KIS Developers) | REST + WebSocket | 가능, 무료 | 국내·해외 모두 있음 | **낮음 — 권장** |
| 키움증권 | OpenAPI+ (OCX, 32bit 윈도우) / 최근 REST 추가 | 가능 | 있음 | 높음 (OCX) / REST면 중간 |
| LS증권 (구 이베스트) | XingAPI (COM/DLL) + REST | 가능 | 있음 | 중간 |
| 대신증권 | CREON Plus (COM, 32bit 윈도우) | 가능 | 있음 | 높음 |
| NH투자증권 | 개인 공개 범위가 제한적 | 확인 필요 | 확인 필요 | 확인 필요 |
| 신한투자증권 | 개인 공개 범위가 제한적 | 확인 필요 | 확인 필요 | 확인 필요 |
| 삼성증권 / 미래에셋 / 토스 / 카카오페이 | 개인용 공개 API 없음 | 불가 | — | — |

베트남 계좌는 국내 증권사 해외지점 계좌라면 API 가 없을 가능성이 큽니다.
베트남 현지 증권사(SSI 의 FastConnect 등)는 개인 API 를 여는 곳이 있습니다.

## 왜 폰에서 직접은 안 되나

1. **CORS** — 증권사 API 는 브라우저에서 오는 요청을 허용하지 않습니다. 폰 브라우저에서
   호출하면 응답을 못 읽습니다.
2. **비밀키 노출** — app secret 을 폰 저장소에 두면 사실상 공개하는 것과 같습니다.
3. **인증 방식** — 대부분 접근토큰 발급/갱신이 필요하고 IP 등록을 요구하는 경우도 있습니다.

그래서 붙인다면 구조는 이렇게 됩니다.

```
증권사 API  ──(app key/secret, PC 안에서만)──▶  내 PC (portfolio serve)
                                                      │
                                        transactions.csv 갱신
                                                      │
                                    ┌─────────────────┴──────────────────┐
                              같은 와이파이 접속            또는  CSV/JSON 백업 파일
                                    ▼                                    ▼
                                 폰 앱(PWA)  ◀── 설정 탭 > 파일 불러오기 ──┘
```

## 그럼 지금 당장 뭘 쓰면 되나 (API 없이)

거의 모든 증권사가 **거래내역을 CSV/엑셀로 내려받게** 해 줍니다. 이 앱은 그걸 그대로 먹습니다.

- 앱: 설정 탭 → `파일 불러오기` (한글 헤더 자동 인식, 중복 자동 제거)
- PC: `python3 -m portfolio import ~/Downloads/거래내역.xlsx`

날짜/종목/구분/수량/단가 컬럼만 있으면 컬럼명이 한글이든 영어든 알아서 읽습니다.
한 달에 한 번 내려받아 넣는 정도면 API 자동화와 실질 차이가 거의 없습니다.

## KIS 를 붙인다면 (설계)

필요한 것: KIS Developers 가입 → 앱 등록 → `APP KEY` / `APP SECRET`, 계좌번호(8자리-2자리).

1. 토큰 발급: `POST /oauth2/tokenP` → `access_token` (유효기간 있으므로 캐시)
2. 국내 잔고: `GET /uapi/domestic-stock/v1/trading/inquire-balance`
   → 종목코드 / 보유수량 / 매입평균가 / 현재가
3. 해외 잔고: `GET /uapi/overseas-stock/v1/trading/inquire-balance`
   → 거래소코드 / 종목 / 수량 / 매입단가(외화)
4. 받은 잔고를 이 시스템의 종목 마스터(국가·통화·섹터)에 매핑

주의할 점 하나: **잔고조회는 "지금 얼마 들고 있나"만 알려줍니다.**
언제 얼마에 샀는지(매매 이력)는 별도 조회이거나 조회 기간 제한이 있습니다.
이 시스템은 이력 기반으로 평단·실현손익을 계산하므로,

- 이력을 못 받으면 → "현재 보유수량 + 매입평균가" 를 **최초 매수 1건처럼** 넣는 방식이 됩니다.
  (평단·평가손익은 맞고, 매수 시점별 이력과 실현손익은 안 맞음)
- 정확히 하려면 → 거래내역 CSV 를 한 번 넣어 과거를 채우고, 이후를 API 로 동기화

## 실제로 붙일 때 필요한 것

원하시면 `portfolio/brokers/kis.py` 로 구현하겠습니다. 다만 이 작업은
**실제 키와 네트워크가 있는 환경에서만 검증**이 되므로, 형님 PC에서 같이 돌려보며
맞춰야 합니다. 키는 절대 저장소에 커밋하지 말고 환경변수로 넣습니다.

```bash
export KIS_APP_KEY=...
export KIS_APP_SECRET=...
export KIS_ACCOUNT=12345678-01
python3 -m portfolio sync-broker kis     # (구현 예정)
```
