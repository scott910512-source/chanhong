# SOP Word 일괄변경 도구

여러 개의 Microsoft Word SOP 문서를 **한 번에 찾기/바꾸기** 해 주는 Windows 프로그램입니다.

자주 쓰는 치환 규칙(예: `생산 관리자` → `생산 관리감독자`)을 한 번 등록해 두면
계속 쌓아서 관리할 수 있고, 필요한 규칙만 ON 으로 켜서 폴더 통째로 적용할 수 있습니다.

> **이 프로그램은 `python-docx` 를 쓰지 않습니다.**
> Microsoft Word 를 직접 조종해서(COM Automation) Word 의 찾기/바꾸기 기능을 실행합니다.
> 그래서 사람이 Word 에서 `Ctrl + H → 모두 바꾸기` 를 누른 것과 **똑같은 결과**가 나오고,
> 글꼴·표·이미지·머리글/바닥글·페이지 번호·스타일 같은 서식이 그대로 유지됩니다.

## 2. Python 설치

> 이미 Python 3.11 이상이 깔려 있다면 이 단계는 건너뛰세요.
> EXE 파일만 받아서 쓰는 분도 이 단계는 필요 없습니다.

1. https://www.python.org/downloads/windows/ 에 들어갑니다.
2. **Python 3.11** 이상 버전의 `Windows installer (64-bit)` 를 내려받습니다.
3. 설치 파일을 실행합니다.
4. **⚠️ 첫 화면에서 아래 두 가지를 꼭 체크하세요.**
   - `Add python.exe to PATH` (맨 아래 체크박스)
   - `Install launcher for all users`
5. `Install Now` 를 누르고 설치가 끝날 때까지 기다립니다.
6. 설치 중간에 나오는 화면에서 **`tcl/tk and IDLE`** 항목이 체크되어 있는지 확인하세요.
   (이 프로그램의 화면을 그리는 데 필요합니다. 기본으로 체크되어 있습니다.)

설치가 잘 됐는지 확인하려면, 시작 메뉴에서 `cmd` 를 검색해 **명령 프롬프트**를 열고
아래를 입력한 뒤 Enter 를 누릅니다.

```
python --version
```

`Python 3.11.x` 처럼 나오면 성공입니다.

## 5. 치환 규칙 추가 방법

### 추가하기

1. 화면 아래쪽의 **`규칙 추가`** 버튼을 누릅니다.
2. 작은 창이 뜹니다.
   - **찾을 문구** : 문서에서 찾을 글자 (예: `생산 관리자`)
   - **바꿀 문구** : 대신 넣을 글자 (예: `생산 관리감독자`)
   - **사용 (ON)** : 체크하면 실제 작업에 적용됩니다.
3. **`저장`** 을 누릅니다. → 목록에 바로 나타나고 파일에도 즉시 저장됩니다.

### 문구를 지우고 싶을 때

**바꿀 문구를 비워 두면** 해당 글자가 문서에서 **삭제**됩니다.

| 찾을 문구 | 바꿀 문구 | 결과 |
|---|---|---|
| `(임시)` | (비워 둠) | 문서에서 `(임시)` 가 사라집니다 |

> **찾을 문구는 비워 둘 수 없습니다.** (실수로 문서 전체가 망가지는 것을 막기 위해서입니다.)

### 수정 / 삭제

- **수정** : 목록에서 규칙을 클릭한 뒤 `수정` 버튼. (규칙을 **더블클릭**해도 됩니다.)
- **삭제** : 목록에서 규칙을 클릭한 뒤 `삭제` 버튼. 확인 창이 한 번 뜹니다.

### ON / OFF 켜고 끄기

- 목록의 **`사용` 칸을 클릭**하면 ON ↔ OFF 가 바뀝니다.
- 규칙을 선택하고 **스페이스바**를 눌러도 됩니다.
- `전체 ON` / `전체 OFF` 버튼으로 한 번에 바꿀 수 있습니다.
- **OFF 인 규칙은 회색으로 표시되고, 실제 작업에 적용되지 않습니다.**

### 적용 순서 바꾸기 (중요)

규칙은 **목록에 보이는 위쪽부터 순서대로** 적용됩니다.

예를 들어 아래 순서라면,

```
1. 생산관리자   →  생산 관리자
2. 생산 관리자  →  생산 관리감독자
```

1번이 먼저 전부 적용된 다음에 2번이 적용됩니다.
(결과적으로 `생산관리자` 도 `생산 관리감독자` 가 됩니다.)

순서를 바꾸려면 규칙을 선택하고 **`▲ 위로`** / **`▼ 아래로`** 버튼을 누르세요.
바뀐 순서는 바로 저장됩니다.

### 중복 방지

**찾을 문구와 바꿀 문구가 모두 같은** 규칙을 또 추가하려고 하면
`동일한 치환 규칙이 이미 등록되어 있습니다.` 라는 안내가 나옵니다.

## 6. 대상 SOP 폴더 선택 방법

1. 화면 가운데 **`대상 폴더`** 칸의 **`폴더 선택`** 버튼을 누릅니다.
2. SOP 문서가 들어 있는 폴더를 고릅니다. (예: `C:\SOP\생산절차서`)
3. 그 폴더 **안의 하위 폴더까지** 처리하고 싶으면 **`하위 폴더 포함`** 을 체크합니다.

### 어떤 파일이 대상인가요?

**포함되는 파일**

- `.docx`
- `.docm`
- `.doc`

**자동으로 제외되는 파일**

- `~$` 로 시작하는 Word 임시 파일 (예: `~$절차서.docx`)
- 백업 폴더 안의 파일 (폴더 이름에 `_원본백업_`, `백업`, `backup` 이 들어간 폴더)

> 선택한 폴더 위치는 자동으로 기억되어, 다음에 프로그램을 켜면 그대로 들어가 있습니다.

## 7. 사전 확인 방법

**실제로 파일을 바꾸기 전에, 무엇이 몇 개나 바뀔지 미리 확인하는 기능입니다.**
이 기능은 **파일을 절대 저장하지 않습니다.** 마음 놓고 눌러도 됩니다.

1. 규칙을 등록하고 대상 폴더를 고릅니다.
2. **`사전 확인`** 버튼을 누릅니다.
3. 잠시 뒤 결과 창이 뜹니다.

```
검사 결과  (실제 파일은 변경하지 않았습니다)

대상 Word 파일 : 38개
적용 규칙 : 12개

변경 예상 문서 : 27개
변경 없음 : 9개
열려 있어 제외 : 2개
읽기 전용 제외 : 0개
오류 : 0개

예상 치환 횟수 : 147회

--------------------------------------------
규칙별 건수
--------------------------------------------
생산 관리자 -> 생산 관리감독자 : 17건
DMA 케비넷 -> DMA Cabinet : 9건
점검 담당자 -> 작업 담당자 : 4건
```

**실제로 바꾸기 전에 항상 이걸 먼저 눌러 보는 것을 권합니다.**

## 8. 실제 일괄변경 방법

1. **`일괄 변경 실행`** 버튼을 누릅니다.
2. 확인 창이 뜹니다.

```
12개의 치환 규칙을
38개의 Word 문서에 적용합니다.

원본 문서는 자동으로 백업됩니다.
Word 에서 열려 있는 문서는 제외됩니다.

계속하시겠습니까?
```

3. **`예`** 를 누르면 작업이 시작됩니다.
4. 화면 아래 진행 막대가 움직입니다.

```
17 / 38   (45%)   DMA_Cabinet_작업절차서.docx
[████████████░░░░░░░░]
```

5. 끝나면 결과 창이 뜹니다.

```
일괄 변경 완료

전체 Word 파일 : 38개
변경된 파일 : 32개
변경 없음 : 4개
열려 있어 제외 : 2개
읽기 전용 제외 : 0개
오류 : 0개

총 치환 횟수 : 147회

원본 백업:
C:\SOP\생산절차서_원본백업_20260827_143500
```

### 제외되거나 오류가 난 파일 보기

메인 화면의 **`제외/오류 파일 보기`** 버튼을 누르면 상세 목록이 나옵니다.

```
[열려 있어서 제외]

1. DMA_Cabinet_SOP.docx
   C:\SOP\생산절차서\DMA_Cabinet_SOP.docx
2. TMA_작업절차서.docx
   C:\SOP\생산절차서\TMA_작업절차서.docx

--------------------------------------------

[오류]

1. Test_SOP.docx
   C:\SOP\생산절차서\Test_SOP.docx
   → 암호가 설정된 문서입니다.
```

### 중간에 멈추고 싶을 때

**`작업 중단`** 버튼을 누르세요.
지금 처리 중인 문서까지만 끝내고 멈춥니다. **이미 바뀐 문서는 그대로 저장되어 있습니다.**

## 9. 백업 위치

문서를 바꾸기 **전에** 원본이 자동으로 복사됩니다.

대상 폴더가

```
C:\SOP\생산절차서
```

라면, 백업은 **바로 옆(같은 상위 폴더)** 에 만들어집니다.

```
C:\SOP\생산절차서_원본백업_20260827_143500
```

- 뒤의 숫자는 작업한 **날짜_시각** 입니다. (`YYYYMMDD_HHMMSS`)
- 하위 폴더가 있으면 **원래 폴더 구조 그대로** 복사됩니다.
- **백업에 실패한 파일은 절대 수정하지 않습니다.**

### 원래대로 되돌리고 싶다면

백업 폴더 안의 파일을 원래 위치에 **덮어쓰기**로 복사하면 됩니다.

> 백업 폴더는 다음번 작업의 **대상에서 자동으로 제외**되므로,
> 그대로 두어도 이중으로 치환되는 일은 없습니다.
> 다만 백업이 계속 쌓이면 용량을 차지하니, 오래된 것은 가끔 지워 주세요.

## 10. EXE 빌드 방법

Python 을 모르는 동료에게 나눠 주려면 EXE 파일로 만들면 됩니다.

1. `build.bat` 파일을 **더블클릭**합니다.
2. 검은 창이 뜨고 자동으로 진행됩니다. (몇 분 걸릴 수 있습니다.)
3. 다 끝나면 아래 파일이 만들어집니다.

```
dist\SOP_Word_일괄변경.exe
```

4. 이 EXE 파일 **하나만** 복사해서 나눠 주면 됩니다.
   받는 쪽에는 Python 이 없어도 되고, **Microsoft Word 만 설치되어 있으면** 됩니다.

> 명령 프롬프트에서 직접 만들고 싶다면:
>
> ```
> pyinstaller --noconsole --onefile --name "SOP_Word_일괄변경" ^
>   --hidden-import win32com.client --hidden-import pythoncom ^
>   --hidden-import pywintypes --hidden-import win32timezone main.py
> ```

**참고:** 백신 프로그램이 PyInstaller 로 만든 EXE 를 오탐지하는 경우가 있습니다.
사내 백신에 걸리면 예외 등록을 요청하세요.

## 11. 주의사항

### ⚠️ 꼭 지켜 주세요

1. **작업 전에 `사전 확인` 을 먼저 눌러 보세요.**
   특히 짧은 단어(예: `관리`)는 엉뚱한 곳까지 바뀔 수 있습니다.

2. **Word 에서 열려 있는 문서는 자동으로 제외됩니다.**
   바꾸고 싶은 문서는 **Word 를 닫은 뒤** 실행하세요.
   (제외되어도 나머지 문서 작업은 그대로 진행됩니다.)

3. **작업 중에는 Word 를 새로 열거나 닫지 마세요.**
   프로그램이 별도의 숨은 Word 를 띄워서 작업하기 때문에,
   중간에 건드리면 예기치 못한 동작이 생길 수 있습니다.
   (단, 이 프로그램은 **여러분이 열어 둔 Word 는 절대 종료하지 않습니다.**)

4. **대소문자를 구분합니다.**
   `DMA` 와 `dma` 는 다른 것으로 봅니다.

5. **문구는 입력한 그대로 찾습니다.**
   Word 의 특수 기호(`^p` 등)나 와일드카드는 쓸 수 없고, 글자 그대로 처리됩니다.

6. **한 문구는 최대 255자까지** 등록할 수 있습니다. (Word 자체 제한입니다.)

### 자동으로 건너뛰는(SKIP) 경우

| 상황 | 처리 |
|---|---|
| Word 에서 이미 열려 있는 문서 | 수정하지 않고 SKIP |
| 읽기 전용 파일 | 수정하지 않고 SKIP |
| 암호가 걸린 문서 | 오류로 기록하고 SKIP |
| 백업에 실패한 파일 | 수정하지 않고 오류로 기록 |
| 파일이 손상되어 열리지 않는 경우 | 오류로 기록하고 다음 문서로 진행 |

**어떤 문서에서 오류가 나도 전체 작업은 멈추지 않고 끝까지 진행됩니다.**

### 안전장치 요약

- 백업이 성공하기 전에는 원본을 절대 건드리지 않습니다.
- 열려 있는 문서, 읽기 전용 파일은 수정하지 않습니다.
- 매크로가 들어 있는 문서(`.docm`)를 열어도 **매크로는 실행되지 않습니다.**
- Word 의 경고창 때문에 프로그램이 멈추지 않도록 처리되어 있습니다.
- 작업이 끝나거나 오류가 나도, 프로그램이 띄운 Word 는 반드시 종료됩니다.
- **여러분이 직접 열어 둔 Word 창과 문서는 건드리지 않습니다.**
- 변경 내용 추적(Track Changes)이 켜진 문서는, 치환하는 동안만 잠시 끄고
  저장 전에 원래 설정으로 되돌립니다.

## 13. 자주 묻는 질문

**Q. 표 안의 글자도 바뀌나요?**
네. 본문, **표**, 머리글, 바닥글, 각주, 미주, 주석, 텍스트 상자까지 모두 처리합니다.

**Q. 서식이 깨지지 않나요?**
Word 자체의 찾기/바꾸기를 쓰기 때문에, 사람이 직접 `Ctrl+H` 로 바꾼 것과 같습니다.
글꼴, 크기, 색, 굵게, 밑줄, 표 크기, 이미지, 페이지 레이아웃, 스타일이 그대로 유지됩니다.

**Q. 문서가 많은데 시간이 오래 걸리나요?**
문서 1개당 Word 로 열고 닫는 시간이 필요합니다. 보통 문서당 1~3초 정도이며,
100개면 몇 분 정도 걸립니다. **작업 중에도 프로그램 창은 멈추지 않습니다.**

**Q. 실행했더니 "pywin32 를 찾을 수 없습니다" 라고 나옵니다.**
[3번 항목](#3-필요한-패키지-설치)의 설치 명령을 다시 실행해 주세요.

```
python -m pip install pywin32
```

**Q. "Microsoft Word 를 실행할 수 없습니다" 라고 나옵니다.**
이 PC 에 Microsoft Word 가 설치되어 있는지 확인하세요.
(한글(HWP)이나 무료 오피스만 있는 경우에는 동작하지 않습니다.)

**Q. 작업 도중 창을 닫으면 어떻게 되나요?**
바로 꺼지지 않고 확인 창이 뜹니다.
`예` = 작업을 중단하고 종료 / `아니오` = 작업이 끝나면 자동 종료 / `취소` = 종료 안 함.

**Q. 실수로 잘못 바꿨어요.**
[9번 항목](#9-백업-위치)의 백업 폴더에서 원본을 되돌리세요.

### 테스트 실행

```

```

실제 Microsoft Word 없이도 동작합니다.
`tests/fake_word.py` 가 Word COM 계층(StoryRange / Find / Replace / Save)을 흉내 내므로,
치환 순서·백업·SKIP·오류 격리·Word 인스턴스 종료 같은 핵심 흐름을 검증할 수 있습니다.

### Word COM 처리 요약

| 항목 | 구현 |
|---|---|
| Word 인스턴스 | `DispatchEx("Word.Application")` — 사용자의 기존 Word 와 분리된 새 프로세스 |
| 화면 | `Visible = False` (숨김) |
| 경고창 | `DisplayAlerts = 0` |
| 매크로 | `AutomationSecurity = 3` (강제 비활성화) |
| 열린 문서 확인 | `GetActiveObject("Word.Application")` 으로 기존 Word 의 `Documents.FullName` 조회 |
| 경로 비교 | `os.path.normcase(os.path.abspath(...))` |
| 처리 영역 | `doc.StoryRanges` 전부 + `NextStoryRange` 체인 끝까지 |
| 치환 | `Find.Text` / `Replacement.Text` / `Execute(Replace=wdReplaceAll)` |
| 건수 집계 | `ReplaceAll` 은 횟수를 돌려주지 않으므로, 치환 직전에 같은 조건으로 미리 센다 |
| 저장 | `doc.Save()` — 원래 파일 형식(.doc/.docx/.docm) 유지 |
| 정리 | `try / finally` 로 문서 Close → `word.Quit()` 보장 |
| 스레드 | 워커 스레드 안에서 `pythoncom.CoInitialize()` ~ `CoUninitialize()` 까지 완결 |

### 왜 python-docx 가 아닌가

`python-docx` 는 XML 을 직접 다루기 때문에, 한 문장이 여러 개의 run 으로 쪼개져 있으면
문구를 제대로 찾지 못하고, 억지로 합치면 서식이 깨집니다.
머리글/바닥글/텍스트 상자/각주 처리도 직접 구현해야 합니다.
Word COM 은 이 모든 것을 Word 엔진이 처리해 주므로, **결과가 사람이 한 것과 동일**합니다.
