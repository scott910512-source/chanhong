# SOP Word 일괄변경 도구 — VBA 버전

**설치할 것도, 디스크에 저장할 파일도 없습니다.**
Word 안에 매크로만 한 번 넣어두면 끝입니다.

Python 버전(`SOP_BatchReplace/`)이 **회사 PC 정책 때문에 안 될 때** 쓰는 버전입니다.

---

## 이 버전의 특징

| 항목 | 내용 |
|---|---|
| 설치 | 필요 없음 (Word 안에 매크로만 넣음) |
| 저장 위치 | **`Normal.dotm`** — Word가 알아서 관리하는 파일 |
| 규칙 저장 | **레지스트리** (HKCU) — 새 파일을 만들지 않음 |
| 적용 범위 | **모든 Word 문서에서 항상 사용 가능** |
| 서식 유지 | Word 자체 찾기/바꾸기 사용 → 서식 그대로 |

> **질문에 대한 답:** VBA 매크로는 파일별로만 저장되는 게 아닙니다.
> `Normal.dotm`(기본 서식 파일)에 넣으면 **모든 문서에서 항상** 쓸 수 있습니다.

---

## 1. 설치 방법 (5분)

### 준비 — 개발 도구 탭 켜기 (한 번만)

1. Word 실행
2. **파일 → 옵션 → 리본 사용자 지정**
3. 오른쪽 목록에서 **`개발 도구`** 체크 → 확인

> 이 단계를 건너뛰고 **`Alt + F11`** 을 바로 눌러도 됩니다.

### 방법 A — 붙여넣기 (권장, 파일 저장 불필요)

1. `SOP_BatchReplace_붙여넣기용.txt` 를 메모장으로 엽니다.
2. **`Ctrl + A`** → **`Ctrl + C`** (전체 복사)
3. Word 에서 **`Alt + F11`** → VBA 편집기가 열립니다.
4. 왼쪽 트리에서 **`Normal`** 을 찾아 **클릭**합니다.
   (`Project (Normal)` 이라고 나옵니다. 문서 이름이 아니라 **Normal** 이어야 합니다.)
5. 메뉴 **삽입 → 모듈**
6. 오른쪽 흰 창을 클릭하고 **`Ctrl + V`** (붙여넣기)
7. **`Ctrl + S`** (저장)
8. VBA 편집기를 닫습니다. (`Alt + Q`)

### 방법 B — 파일 가져오기

1. Word 에서 **`Alt + F11`**
2. 왼쪽 트리에서 **`Normal`** 클릭
3. 메뉴 **파일 → 파일 가져오기**
4. `SOP_BatchReplace.bas` 선택
5. **`Ctrl + S`** → **`Alt + Q`**

### 설치 확인

Word 에서 **`Alt + F8`** → 목록에 **`SOP_Main`** 이 보이면 성공입니다.

## 2. 사용 방법

### 실행

**`Alt + F8`** → **`SOP_Main`** 선택 → **실행**

메인 메뉴가 뜹니다.

```
=== SOP Word 일괄변경 도구 ===

현재 규칙 : 0개  (사용 ON : 0개)

1. 치환 규칙 관리
2. 사전 확인   (파일을 바꾸지 않고 미리 검사)
3. 일괄 변경 실행
4. 규칙 목록 전체 보기
0. 종료

번호를 입력하고 [확인] 을 누르세요:
```

숫자만 입력하고 확인을 누르면 됩니다.

### 규칙 등록 (`1` 입력)

```
1. 규칙 추가        ← 새 규칙 만들기
2. 규칙 수정
3. 규칙 삭제
4. 사용 ON/OFF 전환
5. 전체 ON        6. 전체 OFF
7. 위로 이동      8. 아래로 이동
0. 돌아가기
```

`1` (규칙 추가) 을 누르면 두 번 물어봅니다.

```
[1/2] 찾을 문구 :  생산 관리자
[2/2] 바꿀 문구 :  생산 관리감독자
```

등록된 규칙은 **Word 를 껐다 켜도 그대로 남아 있습니다.**

**문구를 지우고 싶으면** 바꿀 문구를 비워 두고 확인을 누르세요.
(정말 삭제할지 한 번 더 물어봅니다.)

### 적용 순서 (중요)

규칙은 **1번부터 순서대로** 적용됩니다.
`7. 위로 이동` / `8. 아래로 이동` 으로 순서를 바꿀 수 있습니다.

```
1. 생산관리자   →  생산 관리자
2. 생산 관리자  →  생산 관리감독자
```
1번이 전부 끝난 뒤 2번이 적용됩니다.

### 사전 확인 (`2` 입력)

**파일을 절대 바꾸지 않고** 몇 건이나 바뀔지 미리 세어 봅니다.

1. 폴더 선택 창이 뜹니다 → SOP 폴더 선택
2. "하위 폴더까지 포함할까요?" → 예 / 아니오
3. 결과가 나옵니다.

```
검사 결과   (실제 파일은 변경하지 않았습니다)

대상 Word 파일 : 38개
적용 규칙 : 12개

변경 예상 문서 : 27개
변경 없음 : 9개
열려 있어 제외 : 2개
읽기 전용 제외 : 0개
오류 : 0개

예상 치환 횟수 : 147회
```

**실제로 바꾸기 전에 항상 이걸 먼저 해 보세요.**

### 일괄 변경 (`3` 입력)

폴더 선택 → 하위 폴더 여부 → 최종 확인 → 실행.

진행 상황은 Word **아래쪽 상태 표시줄**에 나옵니다.

```
[17/38] 변경 중 ... DMA_Cabinet_작업절차서.docx
```

끝나면 요약 창이 뜨고, **상세 보고서가 새 Word 문서로 열립니다.**
(파일로 저장하지 않으니, 필요하면 직접 저장하거나 인쇄하시면 됩니다.)

## 3. 백업

문서를 바꾸기 **전에** 원본이 자동 복사됩니다.

```
대상 :  C:\SOP\생산절차서
백업 :  C:\SOP\생산절차서_원본백업_20260827_143500
```

- 대상 폴더 **바로 옆(같은 상위 폴더)** 에 만들어집니다.
- 하위 폴더 구조 그대로 복사됩니다.
- **백업에 실패한 파일은 절대 수정하지 않습니다.**
- 백업 폴더는 다음 작업 대상에서 **자동 제외**됩니다.

**되돌리려면** 백업 폴더의 파일을 원래 위치에 덮어쓰기 하세요.

---

## 4. 안전장치

| 상황 | 처리 |
|---|---|
| Word 에서 **이미 열려 있는 문서** | 수정하지 않고 SKIP |
| 읽기 전용 파일 | 수정하지 않고 SKIP |
| 암호가 걸린 문서 | 오류로 기록하고 SKIP (암호 창이 뜨지 않음) |
| 백업 실패 | 수정하지 않고 오류로 기록 |
| 파일이 손상됨 | 오류로 기록하고 **다음 문서로 계속 진행** |
| `~$` 임시 파일 | 대상에서 제외 |
| 백업 폴더 안의 파일 | 대상에서 제외 |

- **어떤 문서에서 오류가 나도 전체 작업은 멈추지 않습니다.**
- 작업 중 Word 경고창이 뜨지 않도록 처리되어 있습니다.
- 변경 내용 추적이 켜진 문서는 치환 동안만 끄고, 저장 전에 원래대로 되돌립니다.
- 작업이 끝나거나 오류가 나도 Word 설정(화면 갱신·경고·상태표시줄)은 **반드시 원래대로 복원**됩니다.

---

## 5. 어디까지 바뀌나요

Word 의 `StoryRanges` 를 전부 순회하므로 아래가 모두 처리됩니다.

- 본문
- **표 안의 텍스트**
- 머리글 / 바닥글 (구역별로 전부)
- 각주 / 미주
- 메모(주석)
- **텍스트 상자 / 도형 안의 글자**

서식(글꼴·크기·색·굵게·밑줄·표·이미지·페이지 레이아웃·스타일)은 **그대로 유지**됩니다.
사람이 `Ctrl + H → 모두 바꾸기` 를 한 것과 같습니다.

---

## 6. 규칙이 저장되는 곳

레지스트리에 저장됩니다. (파일을 만들지 않습니다)

```
HKEY_CURRENT_USER\Software\VB and VBA Program Settings\SOPBatchReplace\Rules
```

- `Count` : 규칙 개수
- `R1`, `R2`, ... : `사용여부 <탭> 찾을문구 <탭> 바꿀문구`

> 다른 PC 로 옮기려면 `regedit` 에서 위 키를 내보내기/가져오기 하면 됩니다.

## 7. 주의사항

1. **작업 전에 `2. 사전 확인` 을 먼저 하세요.** 특히 짧은 단어는 엉뚱한 곳까지 바뀝니다.
2. **바꿀 문서는 Word 에서 닫아 두세요.** 열려 있으면 자동으로 제외됩니다.
3. **작업 중에는 Word 를 건드리지 마세요.** 매크로가 문서를 열고 닫는 중입니다.
4. **대소문자를 구분합니다.** (`DMA` ≠ `dma`)
5. **문구는 입력한 그대로** 찾습니다. Word 특수코드(`^p`)나 와일드카드는 쓸 수 없습니다.
6. **한 문구 최대 255자** (Word 자체 제한)
7. 문서가 많으면 시간이 걸립니다. 상태 표시줄이 움직이면 정상 동작 중입니다.

### 매크로가 실행되지 않을 때

**파일 → 옵션 → 보안 센터 → 보안 센터 설정 → 매크로 설정**

`Normal.dotm` 에 넣은 매크로는 보통 그냥 실행됩니다.
그래도 막히면 사내 IT 담당자에게 문의하세요.

### 매크로를 지우고 싶을 때

`Alt + F11` → 왼쪽 트리 `Normal` → `모듈` → `SOP_BatchReplace` 우클릭 → **제거**

## 8. Python 버전과 비교

| | VBA 버전 | Python 버전 |
|---|---|---|
| 설치 | 불필요 | Python + pywin32 설치 필요 |
| 파일 저장 | **불필요** | 프로그램 파일 저장 필요 |
| 화면 | 입력창(InputBox) 방식 | 제대로 된 GUI 창 |
| 규칙 저장 | 레지스트리 | `%APPDATA%\SOPBatchReplace\rules.json` |
| 로그 | 새 Word 문서로 표시 | 로그 파일로 저장 |
| 배포 | 매크로 복사 | EXE 배포 가능 |
| 기능 | **동일** | **동일** |

치환 성능과 안전장치는 두 버전이 같습니다. 환경에 맞는 쪽을 쓰세요.
